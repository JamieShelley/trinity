# Raven Navy Issue visual truth set

These in-game screenshots define the minimum visual baseline required before UV repair modes unlock.

## Workflow

1. Run `scripts\build\test_nsamdr_real_eve_asset.bat` and select the Raven Navy Issue.
2. In mode 1, inspect every semantic channel and the unresolved overlay.
3. Match the camera to one truth-set reference.
4. Select the corresponding truth target in the control panel.
5. Use **Capture baseline / repaired / difference**.
6. Compare the three captures against the reference and clean control regions.

The baseline does not need to reproduce the complete EVE scene. It must preserve the ship's material identity and leave the real UV defect visible.
